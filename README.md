## Project Structure

The portfolio is organized around projects and technical documentation.

Each project can contain information such as:

- Project overview
- Objectives
- Hardware
- Software
- Technologies used
- Development process
- Images
- Schematics and diagrams
- Results
- Lessons learned
- Future improvements

The goal is not only to show the final result, but also to document the engineering process behind it.
