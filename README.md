# Luciano Bellaver — Engineering Portfolio

Personal portfolio and engineering laboratory focused on documenting projects, experiments, and technical development across hardware and software.

🌐 **Website:** [lucianobellaver.com](https://lucianobellaver.com)

---

## About

This repository contains the source code for my personal portfolio website.

I use the website to document my development as a Computer Engineering student and to showcase projects involving embedded systems, hardware, robotics, 3D printing, automation, infrastructure, and software.

The goal is not only to present finished projects, but also to document the process behind them — including experiments, problems, solutions, and lessons learned.
